## Pasos que seguí

1. Creé una carpeta llamada `taller01` para trabajar la actividad  
2. Descargué el archivo CSV proporcionado  
3. Con ayuda de ChatGPT, hice un script `csv_to_json.py` para convertir el CSV en un archivo `.json bulk insert`  
4. Ejecuté ese script desde la terminal  
5. Creé una base de datos `ejercicio001` 
6. Quité los permisos por defecto de la base creada  
7. Creé un script `.run-1.py` para insertar el JSON en CouchDB usando `_bulk_docs`  
8. Ejecuté ese script desde la terminal  
9. Creé una segunda base de datos `ejercicio002` en CouchDB  
10. Quité los permisos por defecto  
11. Hice un nuevo script `run_2.py` para insertar cada documento de forma individual en CouchDB  
12. Ejecuté el último script desde la terminal  
13. Comprobé que los documentos se insertaron correctamente en CouchDB
